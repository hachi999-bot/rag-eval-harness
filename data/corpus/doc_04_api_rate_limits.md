# API利用制限

ArcLedgerは外部システム連携用にREST APIを提供しています(架空のAPIエンドポイントであり、実在のサービスではありません)。

## レート制限
- Businessプラン: 60リクエスト/分
- Enterpriseプラン: 600リクエスト/分
- 上限を超えるとHTTPステータス429が返却され、レスポンスヘッダーの `Retry-After` 秒数だけ待機する必要があります。

## 認証
APIキーはBearerトークン形式で `Authorization` ヘッダーに付与します。APIキーは管理画面から発行でき、1アカウントにつき最大5個まで発行可能です。漏洩が疑われるキーは即座に無効化してください。

## バッチ取得
一括データ取得エンドポイントは1回のリクエストにつき最大1,000件までのレコードを返します。1,000件を超える場合は `next_cursor` を使ったページネーションが必要です。
